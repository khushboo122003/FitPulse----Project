# FitPulse Health Anomaly Detection System

A machine learning-based health anomaly detection platform developed using Python and Streamlit.

## Features
- Health anomaly prediction
- Data preprocessing
- Interactive dashboard
- Data visualization
- Real-time analysis

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
